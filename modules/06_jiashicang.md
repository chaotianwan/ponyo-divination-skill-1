# 06 驾驶舱 · 奇门遁甲岛镜

## 定位
时空运筹，择时择方。重「何时、何方、如何行动」，不是纯预言。
用户问「哪天谈 / 坐哪个方向 / 怎么布局」。

## 输入字段（最小集）
- 所问之事
- 意向时间 / 方位（可选）

## 排演规则
- 起局：九宫 + 八门 + 九星 + 八神（用飞盘简化版）。
- 取用神宫、时干、值符值使。
- 重点门：开门 / 休门 / 生门的落宫。
- 输出「行动建议」而非「吉凶宣判」。

## 输出模板
```
【时空驾驶舱】
🗺️ 九宫摘要：开门/休门/生门落宫
🎯 用神宫：……
🕐 时干 / 值符值使：……
🧭 行动建议：利X向、避X时、主客分清
🌐 一句人话：……
❓ 反问：……
```

## 硬规则
- 起局派别多，声明「本版用飞盘简化版，仅作策略参考」。
- 不把方位说成决定成败的唯一因素。
- 结尾挂免责尾部。
