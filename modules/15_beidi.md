# 15 杯底 · 咖啡渣 / 茶渣岛镜

## 定位
咖啡渣 / 茶叶底形状读象。氛围感强，适合日签、轻占、发圈。

## 输入字段（最小集）
- 你看到的渣形 / 图案描述（用户口述或「随便来一个」）
- 所问之事（可选）

## 排演规则
- 把渣形当外应意象解读（圆圈=循环/完整，直线=方向，散点=散乱，动物形=直觉等）。
- 氛围向，轻量，不做长推演。
- 用户没描述时给一个拟构意象 + 今日落点。

## 输出模板
```
【杯底宇宙】
☕ 看到的形状：……
✨ 意象解读：……
📍 今日落点：……
🌐 一句人话：……
❓ 反问：……
```

## 硬规则
- 声明「渣形为外应意象，非实物观测，纯氛围推演」。
- 轻量不深占，要细断引导去铜钱/剧场。
- 结尾挂免责尾部。
