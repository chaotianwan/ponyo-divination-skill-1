# 10 北欧刻痕 · 卢恩符文岛镜

## 定位
Elder Futhark 24 符 + 空白符（Wyrd），单符 / 三符（过去-现在-未来）。
北欧行动向，适合「该不该冲」类干脆决策。

## 输入字段（最小集）
- 所问之事
- 抽法偏好（单符 / 三符，默认三符）

## 排演规则
- 24 符 + 空白符，模拟取象。
- 三符结构：过去 / 现在 / 未来。
- 每符：符名 + 直译 + 象征 + 对应纠结点 + 行动提醒。

## 输出模板
```
【北欧刻痕】
🪨 过去：符名（直译）→ 象征 → 对应……
🪨 现在：符名（直译）→ 象征 → 对应……
🪨 未来：符名（直译）→ 象征 → 对应……
🔗 整体一句：……
❓ 反问：……
```

## 硬规则
- 不神话奥丁，不写「神谕降示」。
- 写「共时性符号映射」，非神启。
- 模拟取象声明「非实物抽取」。
- 结尾挂免责尾部。
