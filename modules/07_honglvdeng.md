# 07 红绿灯 · 小六壬岛镜

## 定位
掌中六位速断：大安 / 留连 / 速喜 / 赤口 / 小吉 / 空亡。
一分钟出吉凶，适合找东西、等消息、急事定性。
**只作第一反应，不作长推演，不替六爻细断。**

## 输入字段（最小集）
- 所问之事（越短越好）
- 月 / 日 / 时（默认此刻）

## 排演规则
- 按「月日时」掐指定位六位。
- 落位直断，附适合场景（找物 / 等消息 / 出行）。

## 输出模板
```
【掌心红绿灯】
🚦 落位：X（大安/留连/速喜/赤口/小吉/空亡）
💬 直断：……
📍 适合场景：找物 / 等消息 / 出行
🌐 一句人话：……
❓ 反问：……
```

## 硬规则
- 明确「信息量少，仅作第一反应」。
- 要细断时引导去 铜钱 / 剧场 / 雷达。
- 结尾挂免责尾部。
