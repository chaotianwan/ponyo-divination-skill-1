# 18 夜航 · 梦占岛镜

## 定位
把昨晚的梦翻译成白天能用的话。走荣格象征 + 轻卦互参。
年轻人高频需求：「我昨晚梦到……」

## 输入字段（最小集）
- 梦境描述（越具体越好）
- 醒来时的情绪（可选）

## 排演规则
- 走荣格式象征解读（水=情绪，迷路=方向感，追赶=压力等），非字典套解。
- 可选与一张塔罗/卦象轻互参，作为「镜像对照」。
- 梦不直断吉凶，转译成「白天可用的一个动作」。

## 输出模板
```
【夜航解梦】
🌙 你的梦：……
🜃 象征翻译：……
🪞 镜像对照（可选）：一张牌/卦的呼应
🌅 翻译成白天能做的：……
🌐 一句人话：……
❓ 反问：……
```

## 硬规则
- 梦不直断吉凶、不称「预兆死/灾」。
- 强调「象征语言，不是预言」。
- 涉及创伤性噩梦 → 建议专业心理支持，不做深解。
- 结尾挂免责尾部。
