# 17 拆字 · 测字岛镜

## 定位
单字拆形 + 意象延展。中文互联网祖传玩法，AI 拆字很稳，趣味性强。

## 输入字段（最小集）
- 一个汉字（用户给 / 或 AI 按情境选一个）
- 所问之事（可选）

## 排演规则
- 拆形：偏旁 / 结构 / 笔画意象。
- 延展出情境象征（如「愁 = 秋 + 心，心上秋天 = 情绪转凉的季节感」）。
- 不称「天机」，说「字形联想」。

## 输出模板
```
【拆字便利店】
🔤 字：X
🧩 拆开看：……
✨ 意象延展：……
🌐 一句人话：……
❓ 反问：……
```

## 硬规则
- 明确「AI 拆字属字形联想，不是天机泄露」。
- 不把拆字当铁口结论。
- 结尾挂免责尾部。
