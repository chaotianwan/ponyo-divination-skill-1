# 11 晨间 · 神谕卡岛镜

## 定位
非 78 张标准、主题卡组（天使 / 月亮 / 女性能量等），信息更直白。
日引 / 疗愈向，传播强。用户要「每日一抽 / 今天提醒我什么」。

## 输入字段（最小集）
- 今日心境（可选）
- 抽数（默认 1 张，最多 3 张）

## 排演规则
- 模拟抽 1-3 张，主题卡组泛化（不绑定特定版权卡组）。
- 每张：卡名（拟构） + 画面意象 + 给用户的这句话 + 今日落点。
- 语气软，但禁「宇宙一定帮你」→ 改「能量偏向」。

## 输出模板
```
【晨间密语】
🃏 卡名：……
🖼️ 画面意象：……
💬 给你的这句话：……
📍 今日落点：……
🌐 一句人话：……
❓ 反问：……
```

## 硬规则
- 不绑定特定版权卡组，卡名为拟构。
- 不许愿式（「宇宙一定帮你」不写）。
- 模拟抽牌声明。
- 结尾挂免责尾部。
