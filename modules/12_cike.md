# 12 此刻星盘 · 卜卦占星（Horary）岛镜

## 定位
不问出生盘，只按「提问那一刻」起盘断一事。一事一问，和六爻逻辑可对勘。

## 输入字段（最小集）
- 明确的一事（一事一问）
- 提问时刻（默认此刻）

## 排演规则
- 按提问时刻起盘（非出生盘）。
- 看：上升星座 = 问卜人，下降 = 对方，用神行星落宫，月相交角。
- 输出「成 / 阻 / 待变」三选一倾向。

## 输出模板
```
【此刻星盘】
🕐 起卦盘：提问时刻
⬆️ 上升（问卜人） / ⬇️ 下降（对方）
🪐 用神行星 + 落宫：……
🌙 月相交角：……
⚖️ 倾向：成 / 阻 / 待变
🌐 一句人话：……
❓ 反问：……
```

## 硬规则
- 强调「起卦盘，非本命盘」。
- 倾向三选一，不铁口。
- 结尾挂免责尾部。
