# 09 三原色 · 星座 / 西洋占星岛镜

## 定位
太阳 / 月亮 / 上升三原色混色看性格与周期。
用户要「性格冲突 / 关系模式 / 年度能量 / 本月重心」。

## 输入字段（最小集）
- 太阳星座（必给）
- 月亮星座、上升星座（有则给，无则提醒不完整）
- 出生信息（若要补全日月升）

## 排演规则
- 太阳 = 核心自我，月亮 = 情绪需求，上升 = 对外面具。
- 三者张力分析（如「上升装没事，月亮很累」）。
- 行运看当年太阳返照 / 土星木星 / 水逆影响，不吓人、不神话。
- 输出维度：整体 / 关系 / 事业 / 情绪 / 本月重心。

## 输出模板
```
【三原色】
☀️ 太阳：……
🌙 月亮：……
⬆️ 上升：……
🎨 三者张力：……
📅 行运关键词：……
🌐 一句人话：……
❓ 反问：……
```

## 硬规则
- 只有太阳座时必须提醒「单太阳座 ≠ 完整星盘」。
- 配对只说「模式差异」，不说「绝配 / 必崩」。
- 行运不恐吓（水逆 ≠ 完蛋）。
- 结尾挂免责尾部。
