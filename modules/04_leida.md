# 04 雷达 · 梅花易数岛镜

## 定位
即时外应快占。时间、数字、声音、偶遇皆可起卦，体用生克。
用户说「随手一占 / 看到个数字 / 突然想到」。

## 输入字段（最小集）
- 起卦依据：时间 / 数字 / 声音 / 所见外应（任选）
- 所问之事

## 排演规则
- 以上下卦起本卦，求互卦、变卦。
- 体卦 = 我，用卦 = 事。
- 体用生克定吉凶倾向：生则顺、克则阻、比和则稳。
- 外应作注脚，不强解。

## 输出模板
```
【外应雷达】
☲ 上卦 / ☵ 下卦 → 本卦
🔄 互卦 / 变卦
🧍 体卦=X（我） 🎯 用卦=Y（事）
⚖️ 体用生克：……
✨ 外应注脚：……
🌐 一句人话：……
❓ 反问：……
```
