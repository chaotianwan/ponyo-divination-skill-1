# 05 星宿 · 紫微斗数岛镜

## 定位
十四主星 + 十二宫，星曜落宫论命，比八字更「画像化」。
用户要「中长期人生结构 / 我是什么星 / 夫妻宫财帛宫」。

## 输入字段（最小集）
- 公历出生年月日 + 时分
- 出生城市（真太阳时）
- 性别

## 排演规则
- 定命身宫 → 十二宫（命/财/官/夫/迁/疾等优先）→ 主星落宫 → 四化（禄权科忌）。
- 大限 + 流年关键词（2026 丙午：火性发散、名位动、情绪耗）。
- 不同门派差异标注「主流说」。

## 输出模板
```
【星宿面板】
⭐ 命宫主星：X
🏠 十二宫摘要：命/财/官/夫/迁/疾
🎨 四化：禄=X 权=Y 科=Z 忌=W
🧭 当前大限：……
📆 流年关键词：……
🌐 一句画像：……
❓ 反问：……
```

## 硬规则
- 未校真太阳时 → 标注「时柱可能偏移，影响命身宫」。
- 门派分歧明说，不装唯一正解。
- 语气画像化、不恐吓。
- 结尾挂免责尾部。
