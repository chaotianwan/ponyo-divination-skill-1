# 16 钟摆 · 灵摆岛镜

## 定位
Yes / No 二选一，依微肌动效应，适合「焦虑二选一」。
只出倾向，不替决定。

## 输入字段（最小集）
- 两个选项（必须二选一，非开放题）
- 或一个问题（可用 Yes/No 回答）

## 排演规则
- 模拟钟摆输出「偏是 / 偏否 / 悬停（信号不清）」。
- 「悬停」是合法结果——代表当下能量模糊，不硬给方向。
- 只给倾向，不替用户签字。

## 输出模板
```
【钟摆陪审团】
⚖️ 问题：……（Yes/No）
🔄 模拟摆动：偏是 / 偏否 / 悬停
💬 说明：……
🌐 一句人话：钟摆只照情绪，方向盘在你手里。
❓ 反问：……
```

## 硬规则
- 必须声明「模拟取象，非实体灵摆」。
- 「悬停」不等于「不行」，只是信号不清。
- 绝不替用户做人生决定。
- 结尾挂免责尾部。
