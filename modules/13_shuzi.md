# 13 数字 · 生命灵数岛镜

## 定位
生日 + 姓名化简为路径数、表达数、生命路径。
轻量好算，看性格底色 / 年份主题。

## 输入字段（最小集）
- 公历生日（年月日）
- 姓名（可选，用于表达数）

## 排演规则
- 生命路径数：生日各位数累加至个位（1-9 / 11 / 22 / 33 为主数）。
- 当年流年数：年数 + 生日化简。
- 输出：路径数内核 + 流年主题 + 卡点数字。

## 输出模板
```
【数字底色】
🔢 生命路径数：X（内核：……）
📅 当年流年数：Y（主题：……）
⚠️ 卡点数字：……
🌐 一句人话：……
❓ 反问：……
```

## 硬规则
- 只算不加错，主数 11/22/33 不随意降位。
- 标「心理底色模型，非宿命」。
- 结尾挂免责尾部。
