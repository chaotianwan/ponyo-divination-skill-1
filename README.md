# 卜卜岛 PONYO · 卜卦 Skill

> 不替你定命，只陪你卜一卜。

面向年轻人的东西方卜卦文化助手 Skill，含 **18 面岛镜** + **塔罗 78 张独立剧情页**。AI 生成内容，属传统文化与心理投射式参考，非人类占卜师、非科学预测、不承诺改运。

## 这是什么

一套可直接安装进 **豆包工作（Doubao Work）** 的 Skill。收到用户占卜、解梦、拆字、看运势、二选一等请求时，按路由表选择岛镜，按需加载子模块输出轻量解读。

- 18 面岛镜：龟火 / 气象 / 铜钱 / 雷达 / 星宿 / 驾驶舱 / 红绿灯 / 剧场 / 三原色 / 北欧刻痕 / 晨间 / 此刻星盘 / 数字 / 都市剧 / 杯底 / 钟摆 / 拆字 / 夜航
- 内置安全边界：危机词自动停占、不替代医疗/法律/金融/心理干预、不承诺改运

## 安装到豆包工作

1. 下载本仓库：点击右上角 **Code → Download ZIP**，或直接 clone。
2. 解压后得到 `ponyo-divination-skill` 文件夹。
3. 把整个文件夹放进豆包技能目录：
   `...\Doubao\User Data\Default\.doubao\agent_mode\workspace\.user_skills\`
4. 回到豆包对话，说「抽一张今日签」「卜一卦」等即可触发。

## 使用示例

- 「抽一张今日签」→ 晨间·神谕
- 「这事成不成」→ 铜钱·六爻
- 「解个梦」→ 夜航·梦占
- 「选 A 还是 B」→ 钟摆·灵摆

## 落地提醒

- 真太阳时、六爻装卦、紫微排盘属高精度计算，建议后续挂轻量排盘工具/干支 API，避免 AI 心算误差。
- 首次上线建议先关闭「驾驶舱(奇门)」「气象(八字)」两个重排盘模块，稳定后再开。
- 如需对外商用，上线前请自查「卜卜岛」「PONYO」商标（第 9/35/42 类）。
